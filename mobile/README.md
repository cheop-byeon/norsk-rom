# Norsk Rom mobile

This Expo / React Native app brings listening and speaking practice to Android and iOS. It includes a local media studio: import audio or TXT/VTT/SRT captions, transcribe audio with NB-Whisper, create a CEFR listening lesson with NB Borealis, answer evidence-based questions, and save lessons and quiz progress on the device. Imports are copied into app-private storage; no media or transcript is sent to a server.

The app can use Piper Norwegian Bokmål (`no_NO-talesyntese-medium`) through Sherpa-ONNX for neural offline playback. Its open voice pack is downloaded once into app-private storage; the system Norwegian voice remains a fallback. NB-Whisper Large q5_0 and NB Borealis 1B are optional local model downloads. The app releases the ASR and language model contexts before loading Piper to limit memory pressure.

## Run on Android

Install Android Studio, Java 17, and an Android SDK/emulator. From this directory:

```sh
npm ci
npm run android
```

The first run creates the native Android project and downloads build dependencies such as Gradle, the NDK, and CMake. `android/` is generated by Expo prebuild and intentionally ignored; keep app-specific native settings in Expo config or config plugins.

This is a development build. The JavaScript bundle is served by Metro on the development computer while you work. A release build must bundle the app before it can run independently. Large speech and language models are downloaded on demand after installation.

For an Android phone later, enable Developer options and USB debugging, connect it by USB, accept its debugging prompt, then run `npm run android` and select the device if prompted.

## Run on iOS

On a Mac with the full Xcode app, its iOS platform components, and CocoaPods installed, run `npm ci` and `npm run ios`. Expo generates the ignored `ios/` project and installs native pods, including `whisper.rn`, Sherpa-ONNX, `react-native-fs`, and the PCM microphone stream. Sherpa-ONNX downloads its pinned XCFramework during CocoaPods installation. The generated app requests microphone access with an on-device-use explanation and enables Apple's Extended Virtual Addressing entitlement, which `whisper.rn` recommends for Large models. Review signing in Xcode when prompted. The iOS project can be generated without Xcode using `npx expo prebuild --platform ios --no-install`, but compiling and launching it require Xcode.

GitHub Actions compiles, installs and launches an unsigned iOS Simulator build whenever mobile files change. This verifies the native app build without an iPhone or Apple signing account; physical-device audio and model performance still need a real phone.

## Current limits

- The original authored lesson remains as a demo. Imported source lessons are generated locally with Borealis and should be reviewed; small local models can make mistakes. Push-to-talk and imported audio transcription use local NB-Whisper after its optional model download.
- Device imports currently accept audio (MP3, M4A, WAV, AAC, OGG, Opus, FLAC) plus TXT, VTT, and SRT transcripts. URL fetching, DRM services, and extracting audio from video are not part of the mobile app. Users should import only media they are allowed to use.
- Generated lesson lines can be played individually or together with Piper, or with the installed Norwegian system voice. The original imported recording can also be replayed. Transcript timing alignment to the source audio is not implemented yet.
- The grammar correction and phrase matching are narrow demo rules, not general Norwegian grammar or pronunciation assessment.
- NB-Whisper and Borealis are opt-in downloads from pinned Nasjonalbiblioteket Hugging Face artifacts. Size and SHA-256 are checked before installation. Android has compiled and launched in an emulator; iOS simulator builds compile and launch in CI. On-device model download, inference, microphone capture, latency and memory use still need testing on real phones. Borealis is an experimental preview and uses the Gemma license; review its model card before redistributing it.
- Saved phrases and the local lesson index use AsyncStorage. Full lesson JSON, imported source files, and quiz answers are stored in the app's private files directory and survive app restarts. Removing the app removes this data.
- Run `npm test` and `npm run lint` in this directory for the local checks. Piper synthesis and the long-audio workflow still need validation on a physical Android or iOS phone for speed, sound quality, and memory use.
- See [`../MOBILE_MODELS.md`](../MOBILE_MODELS.md) for the NB model details and device checks. Piper is provided by [Sherpa-ONNX](https://github.com/k2-fsa/sherpa-onnx) and the [Norwegian Talesyntese voice](https://huggingface.co/rhasspy/piper-voices/tree/main/no/no_NO/talesyntese/medium).
- Sherpa-ONNX includes third-party components with separate licenses, including LGPL-licensed FFmpeg. Review its [license notices](https://github.com/XDcobra/react-native-sherpa-onnx#third-party-libraries) before distributing app binaries.
