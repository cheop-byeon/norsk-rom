# Norsk Rom mobile

This Expo / React Native project is the starting point for the Android and iOS apps. It currently contains the earlier scripted practice prototype, local phrase storage, and device text-to-speech. It is not yet connected to the current browser lesson flow or the on-device NB model runtimes.

## Run on Android

Install Android Studio, Java 17, and an Android SDK/emulator. From this directory:

```sh
npm ci
npm run android
```

The first run creates the native Android project and downloads build dependencies such as Gradle, the NDK, and CMake. `android/` is generated by Expo prebuild and intentionally ignored; keep app-specific native settings in Expo config or config plugins.

This is a development build. The JavaScript bundle is served by Metro on the development computer while you work. A release build must bundle the app before it can run independently; neither build mode adds the on-device AI models yet.

For an Android phone later, enable Developer options and USB debugging, connect it by USB, accept its debugging prompt, then run `npm run android` and select the device if prompted.

## Current limits

- Role-play replies and speech input are scripted; the microphone is not connected.
- Listening examples are fictional and spoken by the device's Norwegian TTS voice when available.
- Phrasebook data is stored locally with AsyncStorage.
- NB-Whisper, Borealis, Piper, imported media and generated lessons do not run in this app yet. See [`../MOBILE_MODELS.md`](../MOBILE_MODELS.md) for the planned ASR integration and device checks.
